# Farm Checklist (client mod)

Minecraft 26.2, Fabric. Requires Fabric API and Java 25.

Commands:
- /farmlist list
- /farmlist import <number>  (copies transcription_<number>.txt to clipboard)

Transcription files go in .minecraft/farmlist/transcriptions/.

Build: ./gradlew build  (or let GitHub Actions build it; download the jar from the run's artifacts)
